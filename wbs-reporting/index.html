Internal tool · backend-only

WBS Reporting

A backend automation service for reporting and scheduling, used internally for our own five Shopee Indonesia shops.

No user interface. The service has no frontend, no login page and no public access. It runs as scheduled jobs on our own server and sends its results to our staff's private Telegram group and private Google Sheets. This page only describes the service.

What it does

JobPurposeRuns
Price check For orders completed the previous day, compares the price each item sold for against the shop's own active promotion price, and flags items sold more than 2% below it (for example a wrong discount setting). Daily, 17:00 WIB
Failed-delivery returns Adds failed-delivery parcels to our returns list, matches them with the parcels our warehouse scanned back in, and lists parcels that have not arrived after 24 hours so staff can follow up. Daily, 19:00 WIB

Data handling

  • Only our own shops are connected, each authorized by us in the Shopee Open Platform Console.
  • The service does not store buyer personal data (names, phone numbers, addresses). Reports contain order numbers, waybill numbers, item names and prices.
  • Results go only to a private Telegram group and private Google Sheets used by our staff. Nothing is shared with third parties.
  • API credentials are kept in the server's private configuration, never in source code or on this site.

Shop authorization

This site also hosts the page /callback/. Shopee redirects there after we authorize one of our shops in the Console, so we can copy the one-time authorization code into the service. That page only displays the code in the browser; it sends nothing anywhere.
